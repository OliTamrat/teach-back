# Build log, day by day

Everything in this repository was written during the Meta Global AI Developer Hackathon, Oct 26 to
Nov 4, 2026. This log says what shipped each day so a judge can tell what is new; the commit history
is the record behind it. "Day" is a unit of work, not a calendar day: several landed on Oct 26.

| Day | Date | Shipped |
| --- | --- | --- |
| 1 | Oct 26 | Repository created. Deterministic core: Ethiopian calendar conversion (`src/core/calendar.ts`), critical-fact extraction (`facts.ts`), two-listener comparison, label check and language-mismatch flags (`compare.ts`), teach-back question templates (`question.ts`), 71 unit tests. Interpreter screen in text mode (`src/app/Interpreter.tsx`). Health endpoint. |
| 2 | Oct 26 | Audio path. Browser recorder, one patient turn per clip (`Interpreter.tsx`, Record tab). `POST /api/turn` runs both listeners in parallel: Omnilingual ASR over its HTTP contract (`src/server/asr.ts`) with Muse Spark 1.3 rendering the transcript into English, and Muse Spark 1.2 hearing the same audio directly and reporting language, transcript and English as JSON (`src/server/meta.ts`). Prompts are pure and tested (`src/core/prompts.ts`): they ask the models to render, never to advise or convert a date. Script-and-lexicon language fallback (`src/core/language.ts`). Either listener may be missing; the response says which and why, and the screen shows it. 80 unit tests. Verified end to end against local mocks of both services and a fake microphone in headless Chromium; the real services connect when the keys are in place. |
| 3 | Oct 26 | Reviewer flow closed. Corrections are written into the English at the fact's own words and the final line appears only when a person has decided every flag (`src/core/session.ts`). Session log kept on the device, exported as notes or JSON. Evaluation harness (`src/core/eval.ts`, `npm run eval`): 15 text cases with known facts and planted errors, scored on fact recall and precision, planted errors flagged and false alarms; the report lands in `eval/latest.md`. Its first run found three extraction gaps and one scoring rule worth changing, all fixed with tests: "twice a day" leaked a one-day duration, "not more than three times a day" lost its ceiling, one spelling of the Afaan Oromo month was unknown, and a dropped "not" was only a warning. 91 unit tests. |
| 4 | Oct 26 | Ready for the Oct 31 recording session. `docs/recording-session.md`: protocol, what is measured, consent form, volunteer brief. `eval/recording-script.json`: 60 scripted clinic sentences (30 Amharic, 30 Afaan Oromo, draft translations awaiting native review) plus 10 wrong-language items, with the English source each truth is derived from. `/record` page: one clip per sentence, saved on the device under its case id. Harness extended to audio cases: 70 generated from the script, run through `/api/turn` when `EVAL_SERVER_URL` is set, scored with transcript character error rate as well as fact survival and flags; skipped, never failed, when a recording or the server is absent. Teach-back questions in Amharic and Afaan Oromo as templates (`src/core/question-i18n.ts`), shown as drafts until a native speaker signs them off. Three more extraction gaps found by the script and fixed with tests. 99 unit tests. |
| 5 | Oct 27 | Label path and the real ASR contract. The Omnilingual adapter now speaks the Kintale Space's actual contract, read from that service's code: raw audio body, `X-Language-3` header, Hugging Face token, segments back (`src/server/asr.ts`, tested with a fake fetch). `GET /api/health?probe=asr` asks the Space whether its model is loaded. Muse Voice Transcribe is wired as a fallback first listener only, used when the Space is asleep or absent and named as such on the turn. Label check: SAM 3.1 finds the label in a phone photo (`src/server/sam.ts`, tolerant parsing of the preview's response), the reviewer picks the box when there are several, the browser crops it, Spark reads what is printed (`/api/label/read`), and the existing label-conflict flag gets its real input (`src/app/LabelPhoto.tsx`). Verified end to end in headless Chromium against local mocks of the Space (real contract), the Responses endpoint and Spark vision: record, find two boxes, pick one, read, re-check, label flag raised. The walkthrough caught a wrong pairing in the label comparison (a tablet count against a strength); doses are now compared count with count and amount with amount. 110 unit tests. The first live calls to the Meta API and the Space are still pending the keys. |
| 6 | Oct 27 | Hardened for a public URL. A guard on every model-spending route (`src/core/guard.ts`, pure and tested): an optional access code asked once per device, a per-caller limit per minute, and a daily cap per instance, so a public link cannot drain the shared credit; `/api/health` reports the guard's state and counts. Security headers, an error page that never shows a stack trace, and one structured log line per call with timings and counts and never the content. Phone layout: one column, full-width actions, no sideways scroll at 390 px, verified in headless Chromium on the interpreter and recording screens. Demo video script with shot list and rules of the cut (`docs/demo-script.md`). 115 unit tests. |
| 7 | Oct 27 | Judge-facing README: the problem, the seven steps, an architecture diagram, a table of each Meta tool and why, what was built, evaluation, run and deploy. The day log moves here (its table had been split by blank lines). `docs/submission.md` holds the form text with the measured numbers left as brackets until Nov 1. |
| 8 | Oct 27 | Native review and results, both as workflows rather than promises. `/review`: a native speaker approves or rewrites each draft sentence and each question template, in the polite register, and downloads one JSON file; `npm run review:apply` writes it back (`src/core/review.ts`, pure and tested: a change replaces the draft, an approval keeps it, a language's templates count as reviewed only when all seven are). Question templates moved to `src/core/question-templates.json` so a review lands without touching code. `npm run eval` now also writes `eval/latest.json` with per-language character error rate and fact survival; `npm run results` renders it into the README's Results block and the submission sentence, and writes an honest placeholder until audio has run. Verified: a review produced in headless Chromium applied cleanly, then was reverted. 120 unit tests. |
| 9 | Oct 27 | The judge's first visit. A guided walkthrough opens once per device (and from "How it works" in the header): five steps that load real failure patterns into Paste text and check them, so a stranger on a laptop with no microphone reaches the dropped "not" in under a minute, decides a flag, sees a date that does not exist, sees the label conflict, and is handed the Record tab. Keyboard and focus pass: focus moves to the result after a check, Enter saves a correction and Escape cancels, a skip link to the flags, visible focus on the heading. `docs/handover-terminal-agent.md`: what a session on Oli's own machine must collect, where each value lives, what to run in which order, and what to report back verbatim, so the live connection can be made without this sandbox's network limits. Verified in headless Chromium: all five steps, the Enter-to-save path, focus landing on the flags heading, no walkthrough on a second visit. 120 unit tests. |
| 10 | Oct 27 | Quality gate. GitHub Actions on every push: tests, typecheck, the harness, the build, and a check that the README Results block matches the latest run. An independent code review of `src/` and `scripts/` returned ten findings; all ten were real and all are fixed with regression tests: a decimal comma read as a ten-times dose, nested fact spans garbling a corrected final line and hiding the drug inside a negation in the rendering, an empty first-listener rendering turning the second listener's facts into false flags, a bare year parsed as a day, spoonfuls compared against tablet counts, a third language never flagged, text cases counted as recorded clips, a stale clip duration on the recording page, and the English questions duplicated on the review page. Spoonfuls and grams now normalise to millilitres and milligrams before comparison. `docs/submission-checklist.md`: the week to Nov 4, day by day, with owners and fallbacks. 124 unit tests. |
| 11 | Oct 27 | The README and the submission text rewritten in my own voice: why I built this, as someone from the community who has interpreted in these rooms; who it is for beyond clinics (immigration, benefits, schools); and the diaspora beyond Washington. The technical sections are unchanged. |
| 12 | Oct 27 | Beyond the clinic. A `number` fact type: counts ("four children"), ages, money with its currency, and years. A year said with its calendar is converted ("2011 E.C." is September 2018 to September 2019); a bare year up to 2020 is kept with a note to confirm which calendar, because in this community it could be either. Ages are no longer mistaken for durations. A Setting switch on the screen (Clinic, Immigration, Human services) changes which fact the teach-back question confirms first: dose in a clinic, date in an interview, an amount at a benefits desk. Number question templates in English, Amharic and Afaan Oromo (drafts). Three new text cases in the harness. 127 unit tests. |
| 13 | Oct 27–28 | First live calls, from a session on Oli's machine (commits f57b5fa to c5f98b5): Omnilingual, Spark text, Spark audio on WAV and Spark image confirmed; Voice Transcribe's real two-part request shape learned from three 400s; a listener named only once it has spoken; a session language the script rules out is flagged; a printed prohibition on a label is carried through; an empty SAM answer reports the shape it saw; `npm run smoke` repeats the shape check; decisions 17 to 23. Then, from the first phone turn: the browser's WebM clip was refused by Spark audio and by Voice Transcribe, so every clip is now converted in the browser to 16 kHz mono WAV before upload or download (`src/core/wav.ts`, `src/app/audio.ts`), the one container all three listeners take; decision 24. 142 unit tests. |
| 14 | Oct 28 | The first real Amharic turn, from Oli's phone against the live services, and what it taught: Spark 1.2 heard the Amharic and rendered it; the extractor read "five hundred milligrams" as 100 mg, so number words now come in runs; a turn heard by one listener showed green, so it now carries an unverified warning a person must confirm; an empty rendering now says the model's finish reason. Decisions 25 to 27. 146 unit tests. |
| 15 | Oct 28 | The pivot: the interpreter is checked in both directions. A provider turn records the provider's English, then the interpreter's rendering in the patient's language, hears it back through both listeners and compares fact by fact (`compareWithSource`): changed and dropped critical, added a warning. English as a speech language through all three listeners. Symptoms as a fact type, with qualifiers. "Who is speaking" on the screen, a two-step provider recorder, paste mode for both, and a walkthrough rewritten around a real visit: the patient says what is wrong, a person decides, the provider answers and the interpreter is checked the other way, the bottle from the bag, then the microphone. README, demo script and submission text rewritten to match. Four harness cases for provider turns and symptoms. Decisions 28 and 29. 150 unit tests. |
| 16 | Oct 28 | First live two-way turns, from Oli's phone. The provider turn worked end to end: English in, Amharic interpretation heard back, dropped and added facts shown with the provider's words beside the interpreter's. Three fixes from what they showed: Spark 1.3 was running out of tokens while reasoning (finish_reason=length), so the budget is larger and an empty answer is retried on Spark 1.2; the Voice Transcribe fallback was leading on Amharic over a Spark rendering that heard far more, so Spark leads when the fallback stood in; the Amharic question quoted English words (the fact's words are always the English rendering), so each language has a no-quote wording per fact type, used on every turn. "Waist" is a body part, because that is how Amharic ወገብ comes back. The Space was asleep in every live turn so far; raising its sleep timer is the most important setting before Oct 31. Decisions 30 to 32. 151 unit tests. |
